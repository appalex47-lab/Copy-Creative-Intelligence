# Semántica uniforme de los servicios (adaptador DEMO y futuros)

| Situación                                                                                                                                                                                                                                                                                                                                       | Resultado                                               |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Parámetro ausente o inválido (no es texto o está vacío)                                                                                                                                                                                                                                                                                         | `validation_error`                                      |
| El recurso padre no existe                                                                                                                                                                                                                                                                                                                      | `not_found`                                             |
| El recurso padre existe pero no tiene elementos                                                                                                                                                                                                                                                                                                 | lista vacía (éxito)                                     |
| Un fallo del servicio                                                                                                                                                                                                                                                                                                                           | `Result` fallido o excepción; **nunca** una lista vacía |
| Aplica a `memberships.listForOrganization` y `projects.listForOrganization`. `organizations.listForCurrentUser` e `identity.getCurrentIdentity` no reciben parámetros. No existe un contrato «por usuario» (usuario inexistente no aplica a nivel de contrato); la integridad membresía↔usuario se valida sobre el conjunto de datos.           |
| El adaptador DEMO valida la integridad referencial de su conjunto de datos y **se niega a crearse** si es inconsistente (error de programación, lo captura el Error Boundary). No define reglas de negocio ni permisos multiusuario. Cambio de contrato: se añadió el código `validation_error` (aditivo) y el entorno `preview` en `AppState`. |
