# Instalación local

Requisitos: Node >= 22.22.2 y npm (probado con Node 22.23.4 / npm 10.9.9). `npm ci` instala las versiones exactas del lockfile. No requiere Docker, PostgreSQL, Supabase ni credenciales. `.env.example` es opcional: copiar a `.env.local` (ignorado) solo para cambiar valores públicos.
