# Arquitectura implementada
Ver `docs/architecture/ARQUITECTURA.md`. Resumen: domain → services/contracts → services/adapters/demo → services/index (`createServices`) → app (composición) → hooks/components/layouts/pages. UI solo consume contratos. DEMO: memoria, solo lectura, ids `demo-*`, `origin:'demo'`, sin login/token/sesión. `VITE_DATA_MODE=supabase` → error `not_implemented`. Controles: ESLint `no-restricted-imports` (@supabase/*) y pruebas de arquitectura. Contratos provisionales (User, Organization, Membership, Project, AppState): deben validarse contra el diseño definitivo de Fase 0 (no aprobado). Sin SQL ni migraciones.
